# HD-14: Help Cross-References

## What This Tests

Whether the help text includes navigational pointers that guide users to related documentation or subcommand help.

## How The Test Works

1. Scans `--help` output for cross-reference patterns:
   - "See also"
   - "See '...'" or 'See "..."'
   - "For more information"
   - "For more details"
   - "Use ... --help"
   - "Run ... --help"
   - "Learn more"
   - "See the documentation"
   - "Refer to"
2. Reports all found cross-references

## Pass Criteria

- At least one cross-reference pattern found

## Fail Criteria

- No cross-references found; tools with subcommands are especially expected to include these
