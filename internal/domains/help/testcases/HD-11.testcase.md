# HD-11: Web Documentation Link

## What This Tests

Whether the help text includes a URL pointing to web-based documentation.

## How The Test Works

1. Scans the probe's captured `--help` output for URLs matching `http://` or `https://`
2. Reports all found URLs

## Pass Criteria

- At least one URL found in help output

## Fail Criteria

- No URLs found in help output
