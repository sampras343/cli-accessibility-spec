# HD-16: Flag Value Enumeration

## What This Tests

Whether help text enumerates valid values for enum-type flags rather than leaving users to guess.

## How The Test Works

1. Scans `--help` output for value enumeration patterns:
   - "one of: value1, value2, value3"
   - "[value1|value2|value3]"
   - "{value1, value2, value3}"
   - "(value1|value2|value3)"
   - "choices: ...", "valid values: ...", "allowed values: ..."
   - Inline enumeration like "format: json, table, yaml"
   - Common tristate patterns (always/never/auto)
2. Cross-references with the probe's flag data for flags that take values

## Pass Criteria

- At least one flag value enumeration pattern found

## Fail Criteria

- Flags that take values exist but none enumerate valid options in help text
