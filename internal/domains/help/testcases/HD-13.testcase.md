# HD-13: whatis/apropos Compatibility

## What This Tests

Whether the tool has a whatis database entry, enabling discoverability via `whatis` and `apropos` commands.

## How The Test Works

1. Extracts the binary name from its path
2. Runs `whatis <binary-name>` with a 5-second timeout
3. Checks whether whatis exits 0 with non-empty output

## Pass Criteria

- `whatis <binary-name>` exits 0 and outputs a description

## Fail Criteria

- `whatis` exits non-zero or produces no output

## Notes

whatis entries are typically populated from man page NAME sections. Tools without man pages will also fail this criterion.
