# HD-12: Shell Completion Support

## What This Tests

Whether the tool provides a shell completion mechanism (bash, zsh, fish, etc.).

## How The Test Works

1. Tries multiple completion-related subcommands and flags in order:
   - `completion --help`
   - `completions --help`
   - `completion bash`
   - `completions bash`
   - `--generate-completions`
   - `--completion`
   - `--bash-completion`
2. Passes if any variant exits 0 with non-empty output

## Pass Criteria

- At least one completion mechanism exits 0 and produces output

## Fail Criteria

- None of the tested completion variants succeed
