# HD-10: Typo Suggestion

## What This Tests

Whether the tool suggests corrections when a user misspells a subcommand name.

## How The Test Works

1. Takes the first discovered subcommand and drops the last character to create a typo
2. Runs the binary with the misspelled subcommand
3. Checks stderr and stdout for suggestion patterns: "did you mean", "similar", "perhaps you meant", "most similar", or the correct subcommand name

## Pass Criteria

- Error output contains a suggestion phrase or the correct subcommand name

## Fail Criteria

- No suggestion or correction offered for the misspelled subcommand

## Preconditions

- Tool must have subcommands with at least one subcommand name of 2+ characters
