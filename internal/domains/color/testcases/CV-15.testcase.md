# CV-15: Unicode/Emoji Symbol Accessibility

## What This Tests

Whether Unicode symbols and emoji used as status indicators (such as
✓, ✗, ●, ▶, ⚠) have adjacent text alternatives, ensuring screen
reader users and users with terminals lacking font support can
understand the meaning.

Screen readers announce Unicode characters by their official Unicode
name (e.g., "BLACK RIGHT-POINTING TRIANGLE" for ▶), which is rarely
meaningful in context. Some terminals render unfamiliar symbols as
boxes (tofu). If a symbol is the sole indicator of status, these
users lose information.

## How The Test Works

1. Runs the binary with `--help` and captures output
2. Scans for common status/indicator Unicode characters:
   checkmarks (✓✔), crosses (✗✘), circles (●○◆◇), arrows (▶►→←),
   warning symbols (⚠⚡), info symbols (ℹⓘ), and emoji ranges
3. For each symbol found, checks whether adjacent text (within a few
   characters) contains a meaningful label like [OK], PASS, FAIL,
   Error, Warning, etc.
4. Reports whether symbols are supplementary (with text) or sole
   indicators (without text)

## Pass Criteria

- No Unicode indicator symbols found in output, OR
- All symbols have adjacent text alternatives

## Fail Criteria

- Unicode symbols used as sole status indicators without text labels
