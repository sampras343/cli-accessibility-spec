# CV-13: Terminal Hyperlink Accessibility

## What This Tests

Whether OSC 8 terminal hyperlinks (clickable URLs embedded via escape
sequences) degrade gracefully when the terminal signals reduced
capability via `TERM=dumb` or the user disables styling via `NO_COLOR`.

OSC 8 hyperlinks use the sequence `ESC]8;;URL ST` to create clickable
links in supporting terminal emulators. Tools like `ls --hyperlink`,
GCC (linking error codes to documentation), and Rust's `cargo` use
this feature. Screen readers generally cannot interact with these
hyperlinks, and terminals that don't support OSC 8 may display raw
escape characters.

## How The Test Works

1. Runs the binary with `TERM=dumb` and scans stdout for the OSC 8
   opening sequence `\x1b]8;`. If found, the tool emits hyperlinks
   in a context that cannot render them.
2. Runs the binary with `NO_COLOR=1` and scans for the same pattern.
   Hyperlink sequences are visual enhancements and should be
   suppressed alongside color.

## Pass Criteria

- No OSC 8 sequences (`\x1b]8;`) present when `TERM=dumb`
- No OSC 8 sequences present when `NO_COLOR=1`

## Fail Criteria

- OSC 8 sequences found in output despite `TERM=dumb` or `NO_COLOR=1`
