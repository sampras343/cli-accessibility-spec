# CV-11: High Contrast Mode Support

## What This Tests

Whether the tool produces readable output when the OS high-contrast mode is enabled.

## How The Test Works

This criterion requires manual testing:

1. Enable OS high-contrast mode (Windows: Contrast Themes, macOS: Increase Contrast, GNOME: High Contrast)
2. Open a terminal emulator
3. Run the tool with representative commands
4. Verify all output remains readable and no information is lost

## Pass Criteria

- All output readable in high-contrast mode
- No information conveyed solely through colors overridden by high-contrast theme

## Fail Criteria

- Text invisible or unreadable in high-contrast mode
- Information lost when OS overrides application colors
