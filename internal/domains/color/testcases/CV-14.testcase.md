# CV-14: Foreground-Background Pair Contrast

## What This Tests

Whether foreground-background color pairs set by the tool within its
own output meet a minimum contrast ratio of 4.5:1 (WCAG AA).

CV-9 checks foreground colors against the terminal's background. This
criterion checks cases where the tool sets BOTH foreground AND
background colors — for example, `ls` uses blue-on-green (SGR 34;42,
~1.4:1 contrast) for other-writable directories, and white-on-red
(SGR 37;41) for setuid files.

## How The Test Works

1. Runs the binary and captures output with ANSI codes
2. Parses compound SGR sequences to find pairs where both foreground
   (SGR 30-37, 90-97, 38;5;N, 38;2;R;G;B) and background (SGR 40-47,
   100-107, 48;5;N, 48;2;R;G;B) are set
3. For 4-bit ANSI colors, uses standard xterm default RGB values to
   calculate contrast (these are the values most users will see)
4. Calculates WCAG contrast ratio for each pair
5. Flags any pair with contrast < 4.5:1

## Pass Criteria

- No foreground-background pairs with contrast ratio below 4.5:1
- Or tool does not set both foreground and background colors

## Fail Criteria

- One or more foreground-background pairs have contrast < 4.5:1
  using standard xterm default color values
