# CV-12: Bold/Underline as Structural Cues

## What This Tests

Whether structural information conveyed via SGR styling (bold, underline, inverse) remains discernible when styling is stripped — via text formatting like indentation, prefixes, or blank lines.

## How The Test Works

1. Runs the binary with default output and captures styled text
2. Runs the binary with `TERM=dumb` and captures plain text
3. Compares structural readability: are sections, headings, and emphasis still distinguishable in the dumb output through indentation, blank lines, or text markers?
4. Flags for human review since structural comparison is heuristic

## Pass Criteria

- TERM=dumb output retains structural delineation (blank lines between sections, consistent indentation, text-based headings)
- >90% content similarity between styled and unstyled output

## Fail Criteria

- Structural elements only distinguishable by styling (bold headings with no spacing, underlined items with no prefix)
- Significant content lost when styling is stripped
